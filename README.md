# 🦠 COVID-19 Global Dashboard Analysis | Tableau

## 📌 Project Overview

The **COVID-19 Global Dashboard** is an interactive Tableau visualization project designed to monitor and analyze the worldwide impact of the COVID-19 pandemic across different countries and continents.

The dashboard provides a comprehensive view of key pandemic metrics, including:

* Confirmed Cases
* Death Cases
* Recovery Cases
* Geographic Distribution
* Country-wise Performance Comparison
* Continent-wise Filtering

Through interactive maps, KPI cards, and comparative visualizations, users can explore the spread and severity of COVID-19 across regions and identify trends in infection, recovery, and mortality rates.

---

## 🎯 Project Objectives

* Analyze the global impact of COVID-19 using real-world data.
* Visualize confirmed, death, and recovered cases across countries.
* Compare pandemic statistics across continents.
* Enable users to explore data dynamically through filters and geographic visualizations.
* Present pandemic insights through an intuitive dashboard design.

---

## 📊 Dashboard Features

### 🌍 Global Geographic Analysis

An interactive world map allows users to visualize COVID-19 data geographically and understand the regional spread of the virus.

### 📈 KPI Summary Cards

The dashboard highlights key pandemic indicators:

* Total Confirmed Cases
* Total Deaths
* Total Recoveries

These metrics provide an instant overview of the global situation.

### 📌 Country-wise Analysis

Dedicated visualizations compare:

* Confirmed Cases by Country
* Death Cases by Country
* Recovered Cases by Country

This helps identify the most affected and most recovered countries.

### 🎛 Interactive Filters

Users can dynamically filter dashboard results by:

* Continent
* Country

allowing detailed regional analysis and exploration.
